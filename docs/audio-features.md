# NAN 听觉特征全景表 · Audio Perception Registry

> 本文件是听觉模块的特征权威清单：0–8 层为可实现的全部特征，
> 第 9 层在 agent 与 module 的交互中涌现。实现进展直接在状态列更新。
>
> 状态图例：✅ 已实现　🟡 现成库唾手可得　🔴 需要模型或实验
> 对应系统设计见 `docs/audio-design.md`。

---

## 第 0 层：原始信号（一切的地基）
| 特征 | 说明 | 状态 |
|---|---|---|
| 采样率 / 位深 / 声道数 | 音频的基础物理属性 | ✅ 由设备给定 |
| 时长 / 帧数 | 信号长度 | ✅ |
| 音频格式/编码 | WAV/M4A/AAC… | ✅ |
| 原始波形流 | 未处理的 PCM 浮点/整型流 | ✅ |

## 第 1 层：时域低阶特征（一帧向量）
| 特征 | 说明 | 状态 |
|---|---|---|
| RMS 能量 | 瞬时响度最朴素度量 | ✅ MVP |
| 峰值振幅 | 防削波/钳位 | 🟡 |
| 过零率 ZCR | 区分噪声/语音/音乐的粗指纹 | ✅ W2 |
| 时域包络 | 音量随时间起伏轮廓 | 🟡 |
| 短时能量熵 | 能量的"混乱度" | 🔴 |

## 第 2 层：频域/频谱特征（一帧更粗的指纹）
| 特征 | 说明 | 状态 |
|---|---|---|
| FFT 频谱 | 基础频率分解 | ✅ W2（rfft 每帧） |
| 频谱质心 | 声音"亮"还是"闷" | ✅ W2（滚动均值） |
| 频谱带宽/滚降点 | 高频被截在哪 | 🟡 |
| 频谱平坦度 | 越平越像噪声/摩擦声 | ✅ W2（滚动均值） |
| 梅尔频谱 | 人耳感知刻度的频谱图 | 🟡 |
| MFCC | 语音识别/说话人标配 | 🟡 |
| 色度图 Chroma | 十二音阶能量→音乐/和声 | 🟡 |
| 谐波比 HNR | 有声/清声、沙哑度 | 🟡 |

## 第 3 层：音高与韵律（音色之上的"旋律层"）
| 特征 | 说明 | 状态 |
|---|---|---|
| 基频 F0 / 音高 | 男/女声、语调 | ✅ W3（自相关 75–500Hz，零依赖） |
| 音高轮廓 | 升降调→疑问/陈述/兴奋 | ✅ W3（rising/falling/steady） |
| 共振峰 F1/F2/F3 | 元音空间 | 🟡 |
| 语速/音节率 | 单位时间音节数 | ✅ W3（词/秒，来自词级时间戳） |
| 停顿分布 | 语流的静默结构 | 🟡 |
| 动态范围 | 激昂 vs 平静 | 🟡 |

## 第 4 层：声学"事件"特征（把连续流切成有意义的一段）
| 特征 | 说明 | 状态 |
|---|---|---|
| VAD 语音活动检测 | 哪段是人声 | ✅ MVP（webrtcvad；缺失时能量门限降级） |
| 静音检测 | 环境安静/暂停 | ✅ MVP |
| 瞬态/爆破检测 | 门砰、按键、警报等突发 | ✅ MVP（降噪底+18dB，1s 冷却） |
| 噪声基底估算 | 背景环境音的底噪水平 | ✅ MVP（仅非语音段 EMA 自适应） |
| 信噪比 SNR | 语音相对背景清晰度 | 🟡 |
| 回声/混响比 | 房间大小、空旷感 | 🔴 |

## 第 5 层：扬声器/说话人特征（"这是谁在发声"）
| 特征 | 说明 | 状态 |
|---|---|---|
| 说话人嵌入 (x-vector/ECAPA) | 声纹向量 | ✅ W4（CAM++ via sherpa-onnx，零 torch；同层接口与 ECAPA 等价） |
| 说话人分离 diarization | N 人混声各归其主 | ✅ W4 流式逐句归簇（named 注册表 + 会话匿名簇；句内重叠分离仍 🔴） |
| 声纹注册/识别 | "这是我的用户" | ✅ W4（voices/*.npy 即注册表，目录热扫描；注册写入动作外部化） |
| 性别/年龄/口音粗判 | 人口学近似 | 🟡 |
| 发声风格 | 录音室人声 vs 电话 | 🟡 |

## 第 6 层：声学事件分类（"环境中发生了什么"）
| 特征 | 说明 | 状态 |
|---|---|---|
| 环境音分类 | 键盘/门铃/咳嗽/警报… | 🔴 AudioSet 类模型 |
| 语音/音乐/噪声三分类 | 顶层粗分 | ✅ W2 启发式（speech/tonal/noisy/quiet；tonal≈音乐/持续音） |
| 音乐性检测 | 有无结构性节奏 | 🔴 |
| BPM / beat tracking | 音乐速度与节拍点 | 🟡 librosa |
| 调性与和弦 | 情绪功能 | 🔴 |

## 第 7 层：语音内容（"他说了什么"）
| 特征 | 说明 | 状态 |
|---|---|---|
| 转写文本 STT | 完整的话 | ✅ MVP（faster-whisper base） |
| 词级时间戳 | 每个词几点说的 | ✅ W3（word_timestamps=True） |
| 转写置信度 | 平均词置信度 | ✅ MVP |
| 关键词/热词 | 唤醒词、名字、敏感词 | ✅ W3（NAN_AUDIO_HOTWORDS，文本侧匹配） |
| 语言/方言识别 | 自动检测每段语言 | ✅ MVP（auto） |
| 翻译 | 跨语言理解 | 🟡 |

## 第 8 层：语用/情感/意图（"他心里在想什么"）
| 特征 | 说明 | 状态 |
|---|---|---|
| 情绪/情感分类 | 生气/开心/焦虑/平静 | 🔴 |
| 意图检测 | 提问/命令/陈述/寒暄 | 🔴 |
| 语气/信心 | 请求 vs 命令、确定 vs 怀疑 | 🔴 |
| 对话话轮结构 | 谁接谁 | 🔴 |
| 打断/抢话 | 冲突信号 | 🔴 |
| 呼名检测 | "NAN 你在吗" | ✅ W3 文本侧（声学 KWS 仍 🟡） |
| 语码转换 | 中英夹杂 | 🔴 |

## 第 9 层：跨通道聚合 —— 在 agent 与 module 的交互中涌现
不预先实现；当听觉与屏幕/摄像头/系统模块共享 `<module>` 世界快照时自然产生：

| 可能形态 | 说明 |
|---|---|
| 声源方位/空间定位 | 多麦克风阵列（硬件依赖） |
| 说话人 ↔ 人脸绑定 | 声纹 + CameraModule → "张三在说" |
| 声景叙述 | 整段环境的一句话摘要 |
| 情绪-内容耦合 | 说"没事"但语气紧绷 |
| 唤醒-上下文耦合 | 听到呼唤 + 判断用户是否在和 agent 说话 |
| 世界变化信号 | 声音异常驱动其他模块提高采样焦点 |

## 实现波次

| 波次 | 内容 | 解锁层 |
|---|---|---|
| W1 ✅ | 能量 + VAD 切句 + STT 转写 | L1/L4/L7，感知闭环成立 |
| W2 ✅ | ZCR/质心/平坦度 → 环境四态启发式分类 | L2/L6 部分 |
| W3 ✅ | F0/音高轮廓/语速 + 词级时间戳 + 热词通道 | L3/L7+ |
| W4 ✅ | 声纹注册/识别 + 流式逐句分离（CAM++） | L5 |
| W5（下一波） | AudioSet 环境音细分类 | L6 完全体 |
| W4 | ECAPA 声纹注册 + diarization | L5 |
| W5 | AudioSet 环境音细分类 | L6 完全体 |
| W6 | 情绪/意图（小模型或 LLM 受限解码） | L8 |

## 扩展纪律

1. 新特征先进本表的对应层登记（一行），再写代码；状态列是唯一的进度事实。
2. 实现落入 `utils/audio.py`（算法/DSP）或 `AudioModule`（运行时接线），
   与既有 MVP 代码同构，测试随之补充。
3. 任何新特征的 query 输出仍受"重要性投影"约束：静默不刷屏、去重、有界。
