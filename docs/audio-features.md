# NAN 听觉特征金字塔 · 规划文档 v0

> 视图：从最物理的采样一路到最抽象的对话意图感知。
> 状态标记：✅ 仓库已有件 / 🟡 现成库唾手可得 / 🔴 需要模型或实验。
> MVP 只做 1/2/4/7 层；0–8 层为未来 Audio Module 全量目标，Level 9 在 agent 与 module 交互中涌现。

---

## 第 0 层：原始信号（一切的地基）
| 特征 | 说明 | 状态 |
|---|---|---|
| 采样率 / 位深 / 声道数 | 音频的基础物理属性 | ✅ 由设备给定 |
| 时长 / 帧数 | 信号长度 | ✅ |
| 音频格式/编码 | WAV/M4A/AAC… | ✅ |
| 原始波形流 | 未经处理的 PCM 浮点流 | ✅ |

## 第 1 层：时域低阶特征（一帧向量）
| 特征 | 说明 |
|---|---|
| **RMS 能量** | 瞬时响度的最朴素度量 |
| **峰值振幅** | 波形峰值，防削波/钳位 |
| **过零率 ZCR** | 波形穿越 0 的次数 → 粗略区分噪声/语音/音乐 |
| **时域包络** | 音量随时间起伏的轮廓 |
| **短时能量熵** | 能量的"混乱度" |

## 第 2 层：频域 / 频谱特征（一帧更粗的指纹）
| 特征 | 说明 | 状态 |
|---|---|---|
| **FFT 频谱** | 基础频率分解 | 🟡 numpy/librosa |
| **频谱质心** | 声音"亮"还是"闷" | 🟡 |
| **频谱带宽 / 滚降点** | 高频被截在哪 | 🟡 |
| **频谱平坦度** | 越平越像"噪声/摩擦声" | 🟡 |
| **梅尔频谱** | 人耳感知刻度的频谱图 | 🟡 |
| **MFCC**（梅尔倒谱） | 语音识别/说话人标配 | 🟡 |
| **色度图 Chroma** | 十二音阶能量 → 音乐/和声 | 🟡 |
| **谐波比 HNR** | 有声/清声、沙哑度 | 🟡 |

## 第 3 层：音高与韵律（音色之上的"旋律层"）
| 特征 | 说明 | 状态 |
|---|---|---|
| **基频 F0 / 音高** | 男/女声、说话语调 | 🟡 pyin |
| **音高轮廓** | 声调升降 → 疑问/陈述/兴奋 | 🟡 |
| **共振峰 F1/F2/F3** | 元音空间 → 可近似"说的什么元音" | 🟡 |
| **语速 / 音节率** | 每单位时间音节数 | 🟡 |
| **停顿分布** | 语流中的静默结构 | 🟡 |
| **动态范围** | 响度起伏，激昂 vs 平静 | 🟡 |

## 第 4 层：声学"事件"特征（把连续流切成有意义的一段）
| 特征 | 说明 | 状态 |
|---|---|---|
| **VAD 语音活动检测** | 哪段是人声 | ✅ webrtcvad 已装 |
| **静音检测** | 环境安静/暂停 | 🟡 |
| **瞬态/爆破检测** | 门砰、按键、警报这类突发 | 🟡 |
| **噪声基底估算** | 背景环境音的底噪水平 | 🟡 |
| **信噪比 SNR** | 声音 vs 背景的清晰度 | 🟡 |
| **回声/混响比** | 房间大小、空旷 | 🟡 |

## 第 5 层：扬声器/说话人特征（"这是谁在发声"）
| 特征 | 说明 | 状态 |
|---|---|---|
| **说话人嵌入 (x-vector/ECAPA)** | 声纹向量，用于身份 | 🔴 pyannote |
| **说话人分离 (diarization)** | 从 N 人混声中分出每个人 | 🔴 |
| **声纹注册/识别** | "这是我的用户" | 🔴 |
| **性别/年龄/口音** | 人口学粗判 | 🟡 |
| **声道/发声风格** | 录音室人声 vs 电话 | 🟡 |

## 第 6 层：声学事件（"环境中发生了什么"）
| 特征 | 说明 | 状态 |
|---|---|---|
| **环境音分类** | 键盘、敲击、热水器、门铃、咳嗽、警报… | 🟡 AudioSet 模型 |
| **语音/音乐/噪声三分类** | 顶层粗分 | 🟡 |
| **音乐性** | 有没有结构性节奏、和声 | 🟡 |
| **节奏/BPM** | 音乐速度 | 🟡 |
| **打拍子/beat track** | 打击乐点位置 | 🟡 |
| **调性与和弦** | 什么调，情绪功能 | 🔴 |

## 第 7 层：语音内容（"他说了什么"）
| 特征 | 说明 | 状态 |
|---|---|---|
| **转写文本 STT** | 完整的话 | ✅ `listen.py` 有 |
| **词级时间戳** | 每个词几点说的 | 🟡 |
| **置信度** | 模型对每个词多确定 | 🟡 |
| **关键词/热词** | 唤醒、名字、敏感词 | 🟡 |
| **语言/方言识别** | 中文/英文/口音 | 🟡 |
| **翻译** | 跨语言理解 | 🟡 |

## 第 8 层：语用 / 情感 / 意图（"他心里在想什么"）
| 特征 | 说明 | 状态 |
|---|---|---|
| **情绪/情感分类** | 生气/开心/焦虑/平静… | 🔴 |
| **意图检测** | 提问/命令/陈述/反问/寒暄 | 🔴 |
| **语气/礼貌/信心** | 请求 vs 命令、确定 vs 怀疑 | 🔴 |
| **对话回合结构** | 谁接谁、话轮交替 | 🔴 |
| **打断/抢话** | 对话里的冲突信号 | 🔴 |
| **呼名检测** | "NAN/你在吗" | 🟡 热词 |
| **语码转换** | 中英夹杂、专业黑话 | 🔴 |

## 第 9 层：跨通道聚合（超出现有单一音频）
> 这一层不在 Audio Module 内部实现，而是在 agent 与 module 的交互过程中涌现。

| 特征 | 说明 |
|---|---|
| **声源方位/空间定位** | 声从哪来（需多麦克风/阵列） |
| **说话人-人物绑定** | 声纹 ↔ 摄像头人脸 → "是张三在说" |
| **声景叙述** | 整段环境的自然语言摘要："门开了一声、有人进来坐下，开始说话" |
| **情绪-内容耦合** | 话里说"没事"但语气紧张 |
| **唤醒-上下文耦合** | 听到"今天天气" + 背景电视声 → 用户在跟 agent 说话而不是自言自语 |
| **世界变化信号** | "屏幕在播视频、厨房水开了、有人进来" → 驱动其他模块更聚焦 |

## MVP 目标范围（第 1、2、4、7 层）

1. **第 4 层 VAD/静音/能量**（✅ webrtcvad + sounddevice）→ 决定"什么时候算一句"
2. **第 7 层 STT 转写**（✅ `listen.py`）→ 听到的内容
3. **第 2 层 RMS/响度 + 第 6 层环境音粗分** → 判断"背景环境正在发生什么"

MVP 输出示例：

> [音频] 刚刚 14:32，检测到键盘连续敲击 + 一句"嘿 NAN，帮我看下这个报错"（置信 0.93）——环境无人声，疑似你在工作

## 后续扩展方向

- 0–8 全部纳入 Audio Module 全量目标，随迭代逐个点亮
- 每层都可能成为独立子能力，但统一走：后台采集流 → 自处理 → query 只投影"当前重要"快照
- Level 9 不手写：靠 agent 拿到多个感知快照后自行综合
